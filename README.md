# 🍎 사과게임 (Apple Game / Fruit Box)

드래그하여 사과 번호의 합이 **10**이 되도록 상자를 만들어 사과를 제거하는 웹 브라우저 캐주얼 퍼즐 게임입니다.

## 🎮 게임 특징
- **쾌적한 드래그 조작**: 사과가 있는 칸에 마우스나 터치 영역이 살짝만 걸쳐도 즉시 인식 (AABB 판정)
- **실시간 피드백**: 선택된 사과의 합이 10이 되면 초록색으로 즉시 표시되는 플로팅 말풍선
- **콤보 시스템**: 3초 이내에 연속으로 사과를 맞추면 콤보 보너스 획득
- **사운드 효과**: Web Audio API 기반의 맑은 챠임 효과음 탑재 (외부 음원 파일 불필요)
- **반응형 웹 지원**: PC 및 모바일/태블릿 화면 크기 지원

## 🚀 실행 방법
`index.html` 파일을 더블 클릭하거나 웹 브라우저(Chrome, Edge 등)로 열면 바로 실행됩니다.
GitHub Pages를 활성화하면 웹 링크로도 플레이할 수 있습니다.
